# Le parole delle cyber security

:::{glossary}

Vulnerabilità (*vulnerability*)
: Un *punto debole* del sistema che può essere sfruttato (*exploited*) per portare a termine un *attacco*

Zero Fiducia (*Zero Trust*):
: Un principio di progettazione basato sull'idea che ogni elemento del sistema deve essere considerato inaffidabile e va quindi controllato.


:::
