# Architettura degli Elaboratori

La struttura interna di un sistema di elaborazione è detta **architettura**, il suo studio permette di comprendere il funzionamento di tale sistema. L'architettura interna di un elaboratore comprende tutti i suoi componenti ed il modo in cui essi sono connessi.

Gli *elaboratori* moderni sono sistemi estremamente complessi, ciascuna componente (CPU, RAM, Bus, ...) rappresenta un artefatto ingegneristico di straordinaria complessità risultante da decenni di ricerca e sviluppo. Per questo motivo lo studio delle architetture degli elaboratori deve necessariamente ridursi allo studio di **modelli** di architettura. Semplificando un po', *un modello è una rappresentazione semplificata di un oggetto o fenomeno reale*. La semplificazione è ciò che rende possibile lo studio. Nell'ambito delle architetture degli elaboratori, il modello maggiormente studiato è noto come **modello di von Neumann** o **macchina ad accesso casuale** (**Random Access Machine**). Questo modulo affronta alcuni aspetti importanti dell'architettura di von Neumann offrendo dettagli sul funzionamento interno di CPU e memoria RAM.

:::{attention} Attenzione
Il modello *Random Access Machine* viene spesso indicato con la sigla RAM che più comunemente indica la *Random Access Memory*. Per evitare confusione in questi appunti chiameremo la Random Access Machine, macchina di von Neumann e riservero la sigla RAM per indicare la Random Access Memory.
:::
